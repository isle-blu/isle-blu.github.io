# 네트워크

> 네트워크(Network)는 넷(Net, 그물)과 워크(Work, 일)의 합성어 여러 개의 기기가 연결되어 `데이터를 주고 받을 수 있는 통신망` 자세한 내용은 추후 강의에서 다룰 예정

### 사설 ip와 공인 ip

> ip는 같은 네트워크 사설 ip와 공인 ip로 구분된다.

1. 사설 ip: 같은 Hub에 연결된 단말기끼리 통신할 때 사용되는 ip
    
    - 공유기에서 사용하는 사설 ip의 형태 : `192.168.0.X`, `192.168.1.X`
    
    > Hub? 여러 대의 단말기를 서로 연결하여 하나의 네트워크(LAN)로 만들어주는 가장 기초적인 데이터 중계 장비 현대에는 허브는 구식 장비로 더 발전한 장비인 Switch를 사용, 공유기에도 스위치가 들어있어, 이 역할을 수행한다. 위에서 말하는 허브는 위와 같은 역할을 수행하는 장비라고 생각하면 된다.
    
2. 공인 ip : 전세계 네트워크에서 단 하나 뿐인 인터넷에서 공개적인 주소
    
    - 허브 밖으로 통신할 때 사용하는 사용하는 ip주소이다.
    - 우리가 사용하는 공유기마다 하나의 공인 ip가 할당되어 있다.

## 포트

> ip가 목적지라면, 포트는 데이터가 드나드는 문이다.

- 기기마다 0~65535번의 포트번호를 가지고 있고, 상황에 따라 포트를 열어 통신할 수 있다.
- 모든 네트워크 통신은 ip주소 뒤에 포트번호가 붙는 형식으로 사용된다. ex)`198.168.0.5:5500`

### 대표적인 포트

|포트|대표 의미(언급된 범위)|
|---|---|
|80|HTTP 웹 서버|
|443|HTTPS 웹 서버|
|22|SSH|
|21|FTP|
|23|Telnet|
|5500|Live Server 등 개발용 서버에서 자주 사용하는 포트|
