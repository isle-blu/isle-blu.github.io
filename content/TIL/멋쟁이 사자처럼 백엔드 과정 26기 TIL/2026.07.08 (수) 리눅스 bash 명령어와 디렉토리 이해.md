# 리눅스 Shell

> 리눅스는 윈도우와 달리 GUI가 아닌 CLI인 `Shell`의 사용이 압도적으로 많다. 물론 GUI도 가능하지만, 원격 컴퓨터에 터미널을 통해 접속하면 쉘 화면을 기본으로 보게 된다. 따라서 리눅스 쉘을 통해, 파일을 관리하고 시스템을 제어하는 등 많은 것을 할 수 있다.

## 리눅스 명령어 정리

~~made by Gemini~~

|명령어|주요 용도|실전 활용 예시|예시 설명|
|:--|:--|:--|:--|
|**`pwd`**|현재 작업 디렉토리 경로 출력|`pwd`|현재 내가 위치한 폴더의 전체 경로 표시|
|**`ls`**|디렉토리 내부 목록 조회|`ls -al`|숨김 파일을 포함하여 상세 정보를 리스트로 출력|
|**`cd`**|디렉토리(폴더) 이동|`cd ~/projects`|홈 디렉토리 하위의 projects 폴더로 이동|
|**`mkdir`**|새 디렉토리(폴더) 생성|`mkdir -p src/utils`|`src` 폴더와 그 하위 `utils` 폴더를 동시에 생성|
|**`echo`**|텍스트 출력 및 파일 저장|`echo "HELLO" > init.txt`|화면에 출력하는 대신 `init.txt` 파일에 내용 저장/덮어쓰기|
|**`cat`**|파일 내용 화면 출력/병합|`cat server.log`|`server.log` 파일의 전체 내용을 터미널에 출력|
|**`grep`**|특정 문자열/패턴 검색|`grep -i "error" app.log`|대소문자 구분 없이 `error`가 포함된 행만 검색|
|**`sed`**|파일 내부 텍스트 치환/편집|`sed -i 's/local/prod/g' conf.env`|`conf.env` 파일의 모든 `local`을 `prod`로 원본 직접 수정|
|**`cp`**|파일 또는 폴더 복사|`cp -r config/ config_bak/`|`config` 폴더 전체를 `config_bak`으로 복사|
|**`mv`**|파일 이동 및 이름 변경|`mv old.txt new.txt`|`old.txt` 파일의 이름을 `new.txt`로 변경|
|**`rm`**|파일 또는 폴더 삭제|`rm -rf tmp/`|`tmp` 폴더와 하위 내용을 경고 없이 강제 영구 삭제|
|**`tail`**|파일의 끝부분 출력|`tail -f access.log`|파일 뒷부분을 보며 실시간으로 추가되는 로그 감시|
|**`ps`**|실행 중인 프로세스 확인|`ps -ef \| grep node`|현재 실행 중인 프로세스 중 `node` 관련 프로세스 필터링|
|**`kill`**|프로세스 강제 종료|`kill -9 4821`|프로세스 ID(PID)가 4821인 프로그램을 강제 즉시 종료|
|**`chmod`**|파일/폴더 권한 변경|`chmod +x deploy.sh`|`deploy.sh` 파일에 실행(`x`) 권한을 부여|
|**`df`**|디스크 남은 용량 확인|`df -h`|기가바이트(G), 메가바이트(M) 등 사람이 읽기 편한 단위로 출력|

## 명령어 조합 / 연계

> 쉘에서는 특정 기호를 이용해 **명령어와 명령어**를 조합하거나 연계할 수 있다.

1. `|`(파이프)
    
    - `|`(파이프)는 앞 프로그램의 출력 결과를 뒤 프로그램의 입력 값으로 사용하게 해준다.
    - ex) cat names.txt | grep "e" | sort -r
2. `>`과 `>>`(스트림 리디렉션)
    
    - `>`과 `>>`는 스트림 리디렉션이라고 하며, **명령어와 파일**을 연계해준다.
    - `>`는 덮어 쓰기로 작동하며, `>>`는 이어 쓰기로 동작한다.
    - ex) `echo "로그 추가" >> app.log`

# 리눅스 root 디렉토리 구조 이해

> 리눅스 root 디렉토리는 리눅스 시스템의 최상단에 위치한 디렉토리로, 윈도우의 드라이브(C, D, ...)와 같은 역할을 한다.

- root 디렉토리 구조
    
    ```bash
    .
    ├── bin -> usr/bin # 쉘에서 실행되는 APP 실행 파일을 모아둔 디렉토리
    ├── boot # OS 부팅에 필요한 핵심 파일 저장
    ├── cdrom # CD-ROM 연결 공간 
    ├── dev # 디바이스 정보를 모아둔 디렉토리
    ├── etc # 시스템 설정 파일을 모아둔 디렉토리
    ├── home # 사용자들의 개인 공간을 모아둔 디렉토리
    ├── lib -> usr/lib
    ├── lib64 -> usr/lib64
    ├── lost+found
    ├── media # USB, CD-ROM와 같은 이동식 매체의 연결 공간
    ├── mnt # 관리자가 직접 장치를 연결하는 공간
    ├── opt # GUI APP 실행파일(규모가 큰)을 모아둔 디렉토리
    ├── proc
    ├── root # 시스템 관리 권한을 과진 최고 관리자 계정 전용 홈 디렉토리
    ├── run
    ├── sbin -> usr/sbin # 시스템 관리자만 사용할 수 있는 관리용 APP 실행 파일을 모아둔 디렉토리
    ├── snap
    ├── srv
    ├── swap.img
    ├── sys
    ├── tmp
    ├── usr # APP들이 저장되는 디렉토리, 윈도우의 Program Files와 같은 역할
    └── var # 계속 변하는, 가변성 데이터를 저장하는 디렉토리
    ```
    
- 디렉토리 별 용도 정리
    
   |디렉토리 경로|역할 및 용도 설명|비유 및 특징|
    |:--|:--|:--|
    |**`/bin`**|쉘에서 실행되는 일반 APP 실행 파일(명령어)을 모아둔 곳|`/usr/bin`으로 연결(바로가기)됨|
    |**`/boot`**|OS 부팅에 필요한 핵심 파일 저장|커널 이미지 등이 위치함|
    |**`/cdrom`**|CD-ROM 연결 공간|설치 미디어나 호환성을 위해 존재|
    |**`/dev`**|디바이스 정보를 모아둔 디렉토리|리눅스에서는 장치도 파일로 관리함|
    |**`/etc`**|시스템 및 프로그램의 설정 파일을 모아둔 디렉토리|윈도우의 레지스트리와 유사한 역할|
    |**`/home`**|일반 사용자들의 개인 작업 공간을 모아둔 디렉토리|사용자별 독립된 폴더 제공|
    |**`/media`**|USB, CD-ROM과 같은 이동식 매체의 자동 연결 공간|탈부착식 장치 전용|
    |**`/mnt`**|관리자가 직접 장치를 연결하는 수동 공간|추가 디스크 등을 수동 마운트할 때 사용|
    |**`/opt`**|규모가 큰 GUI APP 등의 실행파일을 모아둔 디렉토리|3rd-party 독립형 프로그램 저장소|
    |**`/root`**|최고 관리자(root 계정) 전용 홈 디렉토리|일반 사용자 홈(`/home`)과 철저히 분리됨|
    |**`/sbin`**|시스템 관리자만 사용할 수 있는 관리용 APP 실행 파일 보관|`/usr/sbin`으로 연결(바로가기)됨|
    |**`/usr`**|APP들이 저장되는 디렉토리|**윈도우의 `Program Files`와 같은 역할**|
    |**`/var`**|시스템 운영 중 계속 변하는 가변성 데이터를 저장하는 곳|로그(log), 메일 큐 등이 쌓이는 공간|
