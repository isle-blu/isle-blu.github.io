# Git 협업을 위한 사전 작업과 절차 - Github활용

## Git hub CLI 설치 및 설정

> 설치 기기는 mac으로 한정

### 설치 - homebrew를 이용해 설치

````
```bash
brew install gh
``` 
````

### 초기 로그인

- 로그인 명령어와 선택
    
    ```bash
    gh auth login
    ? What account do you want to log into? 
      → GitHub.com 선택
    
    ? What is your preferred protocol for Git operations? 
      → HTTPS 선택
    
    ? Authenticate Git with your GitHub credentials? 
      → Yes 선택
    ```
    
- 브라우저 방식
    
    ```bash
    
    
    ? How would you like to authenticate GitHub CLI? 
      → Login with a web browser 선택
    ```
    
- 토큰(PAT) 방식
    - PAT 생성 github 사이트에서, 프로필 사진은 클릭 후 `Settings` 클릭 ![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/b9fb130a-97ab-46aa-90eb-8df4d5199a6a.png)
        
        스크로를 내려 가장 하단에 `Developer settings`를 클릭 ![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/6b4eff3a-d511-47fb-b194-d0a7f7dc5b67.png)
        
        메뉴에 `Personal access tokens'를 클릭 후, 그 아래` Fine-grained tokens`를 클릭 ![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/31b133a1-aa58-4a32-8330-6cd8eeaffb74.png)

    - PAT를 통해 로그인
        
        ```bash
        ? How would you like to authenticate GitHub CLI? 
          → Paste an authentication token 선택
        
        ? Paste your authentication token: 
          → <PAT> 붙여넣기
        ```
        

## Github 협업 시작하기

1. github에서 협업할 project의 git repository 생성
2. 각자의 로컬 디렉토리에 해당 프로젝트 저장소를 clone
3. 저장소를 생성한 팀원이 다른 팀원을 Collaborators에 추가 ![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/09ac4ad0-d295-419a-be32-3d3b0a2e6508.png)
4. 이제 팀원들이 원하는 상황에 push, pull 가능

# 동기적 / 비동기적 개발

> 개발 협업의 방식으로 동기적 개발과, 비동기적 개발의 차이를 알아보자.

## 업무의 구분 방식

> 개발 업무를 팀원들끼리 나눈다고 했을 때, 일반적으로 기능(시스템, 도메인) 단위로 구분

- 고려해야할 점
    1. 기능 개발에 순서가 필요한가?
    2. 각 기능을 동시에 병행해서 개발했을 때 문제가 발생할 수 있나?

=> 위와 같은 점을 고민해서 할 수 있는 선택이 `동기적 개발`과 `비동기적 개발`이다.
