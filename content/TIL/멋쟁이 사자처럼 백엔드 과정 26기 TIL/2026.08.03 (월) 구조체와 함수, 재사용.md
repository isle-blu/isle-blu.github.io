# 구조체와 함수

오늘 수업 시작에는 지난 시간에 학습했던 구조체와 함수에 대해 다시 보는 시간을 가졌다. 이 시간을 가진 이유는 변수 뿐 아니라 **함수도 많아지는 상황**에 어떻게 함수를 관리할 것인지를 고민하는데 구조체와 함수에 대한 이해가 필요하기 때문이다.

> 함수의 매개변수와 구조체 이전까지는 함수의 매개변수로 속성 각각을 담았다. 하지만 그렇게 매개변수를 놓고 호출하면 여러 문제가 생길 수 있다.

1. 매개변수 작성 시 실수가 많이 발생
2. 코드가 복잡해질 경우 사용이 어려움
3. 각 변수가 어떤 것을 의미하는 지 빠르게 파악이 어려움

등등 다양한 이유가 있다. 그래서 그룹핑을 통해 만들어진 구조체를 매개변수를 넣게되면, 위와 같은 문제를 예방할 수 있다.

예를 들어,

1. 매개변수 실수 차단
2. 의미단위로 묶여 가독성이 좋음
3. 관련 데이터를 한번에 옮기기 쉬움
4. 함수를 통해 원하는 값을 변경되게 하기 좋음

```java
static void printStudentSeparate(String name, int kor, int eng, int math) {
    System.out.printf("이름: %s, 국어: %d, 영어: %d, 수학: %d%n", name, kor, eng, math);
}
```

```java
static void printStudent(Student s) {
    System.out.printf("이름: %s, 국어: %d, 영어: %d, 수학: %d%n", s.name, s.kor, s.eng, s.math);
}
```

위 예시와 같이, 하나의 매개변수로 원하는 데이터를 모두 넘길 수 있고, 가독성과 관리 측면에서 훨씬 수월한 것을 알 수 있다.

## 재사용

> 구조체와 함수는 코드의 **재사용**이라는 큰 장점이 있다.

구조체와 함수는 모두 **grouping**의 결과이다. 따라서 원하는 곳에서 선언하거나 호출하는 방식으로 코드를 재사용할 수 있다.

하지만 함수의 경우, 하나의 프로그램 안에만 종속될 경우, 그 프로그램 밖에서 재사용할 수 없다는 문제가 있다. 밖에서도 재사용하기 위해 함수를 구조체(자바의 class)에 넣어서 구조체와 함께 재사용하게 할 수 있다.

이와 같은 방식은 여러 장점이 있다.

1. 함수의 재사용
2. 구조체에 적합한 함수 등록....

> 배포와 재사용

자바로 개발한 프로그램을 실행하면, `main`함수를 먼저 실행한다. 이 함수가 있는 코드가 프로그램의 주체이다. 하지만, `main`함수와 함께 있는 구조체나 함수는 다른 곳에서 재사용할 수 없다. 그래서 배포 시에, `main`함수가 있는 코드와 재사용할 코드는 **별도로 압축해서 배포**하게 된다.
