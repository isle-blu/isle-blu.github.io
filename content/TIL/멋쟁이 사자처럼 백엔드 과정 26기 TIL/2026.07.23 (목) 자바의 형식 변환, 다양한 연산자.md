# 자바의 명시적 / 묵시적 형식 변환

> 자바는 **서로 다른 자료형**끼리 연산하거나 대입할 때, 자료형의 변환이 필요할 때가 있다.

- 값을 연산하거나 저장할 때 같은 정수 혹은 실수를 담더라도, 자료형의 크기가 다르면 원칙적으로 에러가 발생하는게 맞다.
- 그래서 값을 자료형이 다른 변수에 저장할 때는 직접 형변환을 해줘야 한다.

```java
int x = 10;
byte y = (byte) x; // 명시적 형식 변환
```

- 하지만 C, C++, Java는 작은 자료형을 큰 자료형에 넣는 확장 변환은 묵시적으로 허용한다.(다르게 말하면 허용하지 않는 언어도 있다.)

```java
byte x = 10;
int y = x; // 묵시적 형식 변환 허용
```

---

- 묵시적 형식 변환이 이뤄지면 작은 자료형을 큰 자료형으로 확장해도 새로 채워지는 bit는 부호를 나타내는 수로 채워진다. => 원본이 되는 값은 유지되기 때문에 문제가 발생하지 않는다.
- 하지만 큰 자료형이 작은 자료형으로 축소하는 변환은 크기가 줄어들면서 앞에 bit들이 잘릴 수 있다. => 실제로 명시적 형변환을 하면 앞 부분이 사라진다.

```java
int a = 300;
byte b = (byte) a;

/*
300을 32비트로 표현: 00000000 00000000 00000001 00101100
                                          └── byte(8비트)는 이 뒤쪽만 가져감

잘라낸 결과 (8비트만 남김): 00101100
*/

System.out.println(b); // 44
```

# 자바의 연산자

> 자바에서 사용하는 산술 연산자, 비교 연산자, 논리 연산자에 대해 설명하고자 한다.

## 산술 연산자

|연산자|이름|설명|예시|결과|
|---|---|---|---|---|
|`+`|덧셈|두 값을 더함|`5 + 3`|`8`|
|`-`|뺄셈|왼쪽에서 오른쪽을 뺌|`5 - 3`|`2`|
|`*`|곱셈|두 값을 곱함|`5 * 3`|`15`|
|`/`|나눗셈|왼쪽을 오른쪽으로 나눔 (정수끼리는 몫만)|`5 / 3`|`1`|
|`%`|나머지|나눗셈의 나머지를 구함|`5 % 3`|`2`|
|`++`|증가|값을 1 증가 (전위/후위 차이 있음)|`x++`, `++x`|`x + 1`|
|`--`|감소|값을 1 감소 (전위/후위 차이 있음)|`x--`, `--x`|`x - 1`|

- 흔히 사용하는 수학적 계산을 위한 연산자다.
- 그 중, 일반적인 수학과 다른 것이 '/'와 '%'다.
    - `/` : 실수끼리의 연산에서는 소수점이 포함된 실수 결과값을 도출하지만, 정수끼리 계산하게 되면 오직 몫을 구한다.
    - `%` : 나눴을 때 남은 나머지를 별도로 구하는 연산자다.
- `++`와 `--` : 각각 1씩 더하고 빼는 연산자다. 하지만 변수 앞 뒤 중 어디에 위치하냐에 따라 약간의 차이가 있다. 따라서 정확한 구분이 필요하다.
    - 앞 : 변수가 위치한 곳의 연산이 시작하기 전에 더하거나 뺀다.
    - 뒤 : 변수가 위치한 곳의 연산이 끝난 후에 더하거나 뺀다.

## 비교 연산자와 논리 연산자

> 참과 거짓을 판단, 즉 진리 값(boolean)을 구하고자할 때 사용한다.

### 비교 연산자

> 값의 크기를 비교하는 연산자다.

|연산자|이름|설명|예시|결과|
|---|---|---|---|---|
|`==`|같음|두 값이 같은지 비교|`5 == 3`|`false`|
|`!=`|다름|두 값이 다른지 비교|`5 != 3`|`true`|
|`>`|초과|왼쪽이 더 큰지 비교|`5 > 3`|`true`|
|`<`|미만|왼쪽이 더 작은지 비교|`5 < 3`|`false`|
|`>=`|이상|왼쪽이 크거나 같은지 비교|`5 >= 5`|`true`|
|`<=`|이하|왼쪽이 작거나 같은지 비교|`5 <= 3`|`false`|

- 수학에서 비교처럼 `=`하나만 쓰면 대입의 의미가 있기 때문에 `==`와 같이 2개를 사용한다.

### 논리 연산자

> 논리 연산자는 비교의 결과가 여러 개일 경우 판단 기준을 만들어주는 연산자다.

|연산자|이름|설명|예시|결과|
|---|---|---|---|---|
|`&&`|논리 AND|둘 다 참이어야 참 (단축 평가)|`true && false`|`false`|
|`\|`|논리 OR|둘 중 하나만 참이어도 참 (단축 평가)|`true \| false`|`true`|
|`!`|논리 NOT|참/거짓을 반전|`!true`|`false`|
|`&`|논리 AND (비단축)|둘 다 참이어야 참, 양쪽 다 항상 평가|`true & false`|`false`|
|`\|`|논리 OR (비단축)|둘 중 하나만 참이어도 참, 양쪽 다 항상 평가|`true \| false`|`true`|

- **and**와 **or**, **not**에 해당하는 연산자다.
- and는 둘 다 참, or는 둘 중 하나가 참인 경우 true를 반환한다.
- not은 뒤에 있는 결과의 참/거짓을 반대로 만든다.
- 비단축(ai가 알려줘서 처음 알았다;;) :
    - 일반적으로 사용하는 기호를 2번 넣는 연산자는 앞에서 참/거짓이 확정되면 바로 결과를 도출한다.
    - 하지만 비단축 연산자는 앞에서 결과가 나오던 말던 무조건 양쪽 다 참/거짓을 확인한다.

## 복합 대입 연산자

> 연산 결과를 연산에 사용한 변수에 다시 대입하는 코드를 좀 더 이해하기 쉽게 하기 위해 만들어진 연산자이다.

|연산자|이름|설명|예시|동일한 표현|
|---|---|---|---|---|
|`+=`|덧셈 대입|더한 값을 다시 대입|`x += 3`|`x = x + 3`|
|`-=`|뺄셈 대입|뺀 값을 다시 대입|`x -= 3`|`x = x - 3`|
|`*=`|곱셈 대입|곱한 값을 다시 대입|`x *= 3`|`x = x * 3`|
|`/=`|나눗셈 대입|나눈 값을 다시 대입|`x /= 3`|`x = x / 3`|
|`%=`|나머지 대입|나머지 값을 다시 대입|`x %= 3`|`x = x % 3`|
|`&=`|AND 대입|비트 AND한 값을 다시 대입|`x &= 3`|`x = x & 3`|
|`\|=`|OR 대입|비트 OR한 값을 다시 대입|`x \|= 3`|`x = x \| 3`|
|`^=`|XOR 대입|비트 XOR한 값을 다시 대입|`x ^= 3`|`x = x ^ 3`|
|`<<=`|왼쪽 시프트 대입|왼쪽으로 민 값을 다시 대입|`x <<= 2`|`x = x << 2`|
|`>>=`|오른쪽 시프트 대입|오른쪽으로 민 값을 다시 대입|`x >>= 2`|`x = x >> 2`|
|`>>>=`|부호 없는 시프트 대입|부호 무시하고 오른쪽으로 민 값을 다시 대입|`x >>>= 2`|`x = x >>> 2`|

- 일반적으로 총합을 구하려면 `sum = sum + number;`와 같은 코드를 작성한다.
- 좀 더 직관적으로 이해하기 위해 복합 대입 연산자를 사용하면 `sum += number`로 변수에 그래도 더해는 것처럼 보인다. -> 이해가 더 수월하다.

## 비트 연산자

> > 비트의 이동 혹은 비트끼리 합쳐질 때 사용하는 연산자다.

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/f118a12a-2f1b-4399-a092-b22c1d10023a.png)

- 모든 데이터는 bit 단위로 이뤄져있다. 그 bit를 움직이거나 bit끼리 비교하며 값을 구하는 연산자다.
- `<<`와 `>>` : 비트를 이동시키는 연산자로 방향에 따라 좌 / 우로 이동한다.
    - 왼쪽으로 이동 시에는 이동한 곳에 0이 채워진다.
    - 오른쪽으로 이동 시 부호에 해당하는 bit의 값이 채워진다.(양수 0, 음수 1)
- `&`, `|`, `^` : 두 수가 비트 단위로 합쳐질 때 방식을 정하는 연산자다.
    - `&` : AND 연산으로 둘 다 1인 경우에만 1이다.
    - `|` : OR 연산으로 둘 중 하나라도 1인 경우 1이다.
    - `^` : XOR 연산으로 둘이 같지 않을 때 1이다.
- `~` : NOT 연산으로 현재 비트를 모두 반전시킨다.(1 -> 0, 0 -> 1)
