# 시스템

- 공동의 목적을 위한 체계, 체제
- **유기적인** 결합체
- 개발자가 시스템에서 하는 일은? => **시스템을 관리하는 관리 시스템 개발**

## IT에서의 시스템

- CRUD : 가장 기초가 되는 시스템
    - Create
    - Read(Retrieve)
    - Update
    - Delete
- 관리 시스템 : CRUD가 모두 포함되어 관리를 목적으로 한 시스템
    - ex) 메뉴 관리, 주문 관리, 사용자 관리
- 그 이외
    - 관리 시스템에서 CRUD 중 일부를 떼어서 별도의 용도로 활용하는 시스템
    - ex) 메뉴 조회, 주문 내역 조회

> 역할자? 해당 시스템을 사용하는 주체

## 카페 웹 앱에서의 시스템 예시

"시스템 : 역할자, 시스템의 기능" 형식으로 아래 작성

- 인덱스 페이지 : 익명사용자, 해당 페이지에 처음 접속했을 때 보이는 페이지
- 메뉴 관리 : 관리자, 메뉴에 대한 CRUD를 담당
- 메뉴 조회 : 고객, 고객에게 메뉴 조회(READ)를 제공
- 장바구니 : 고객, 장바구니에 담을 혹은 담은 메뉴에 대한 CRUD
- 주문 : 고객, 관리자가 보게될 주문관리 / 고객이 보게될 주문 내역에 주문을 추가
- 결제 : 고객, 주문에 추가된 메뉴들을 결제
- 주문 관리 : 관리자, 들어온 주문들에 대한 CRUD
- 주문 내역 조회 : 고객, 주문한 내용에 대한 조회(READ)

## 웹 앱을 개발할 때 디렉토리에 대해

- 만든 웹 서비스에 접속하면 [http://서버/home](http://xn--hk3b17f/home) directory/index.html의 형식으로 들어가게 됨.
- 위와 같이 개발한 workspace의 디렉토리를 따라가며 url로 구성 => 디렉토리 구성에서 개발 시 편의성, url 구조 등을 고려

> 디렉토리 명에서 복수형을 쓰는 경우는? 관리 대상이 되는 리소스에 해당하면 복수형 사용 나머지는 식별자 => 이러한 방식을 Clean URL이라고 함.

> Colocation 방식? 파일 형식이 아닌 **기능, 역할자** 단위로 디렉토리를 구성하는 방식 디렉토리를 찾아다닐 필요 없이, 한 디렉토리에서 해당 기능, 역할자에 대한 것을 모두 해결할 수 있음.

## 바이브 코딩 시 절차

- 개발하는 서비스의 시나리오 흐름(동작하는 시스템의 순서)에 맞게 절차적으로 개발
- ai가 여러 영역을 걸쳐 코딩하며 생길 수 있는 문제 예방
- ex) 카페 웹 : 공통 영역 -> 메뉴 관리 -> 메뉴 조회 -> 장바구니 -> 주문 -> 결제 -> 주문 관리 -> 주문 내역 조회

# Git

대표적인 버전 관리 도구

> 버전 관리 도구? 버전 : 복원을 위한 복구 정보 이걸 돕는 도구를 "버전 관리 도구"라고 함

- 리눅스 / 맥의 Shell, git bash에서 명령어로 사용 가능

## Git 명령어

|명령어|동작|
|---|---|
|git init|현재 디렉토리를 git 관리하도록 초기화|
|git add <파일 or 디렉토리>|해당 파일/디렉토리를 git 저장소의 index에 묶음|
|git add .|현재 디렉토리 하위 파일/디렉토리 모두 add|
|git status|현재 저장소의 상태 확인|
|git commit|".git" 폴더에 commit 메시지와 함께 저장|
|git config|작성자에 대한 데이터 저장|

## +Shell 명령어

| 명령어   | 동작                                            |
| ----- | --------------------------------------------- |
| cd    | change directory, 디렉토리 변경                     |
| cd .. | 상위 디렉토리로 변경                                   |
| cd ~  | 홈 디렉토리로 변경                                    |
| pwd   | 현재 shell이 가리키고 있는 위치 출력                       |
| ls    | list, 현재 디렉토리 안에 있는 파일, 폴더들의 이름을 출력           |
| ls -a | list all, 현재 디렉토리 안에 숨겨진 파일, 폴더 들의 이름까지 모두 출력 |
