# 추상 class

> 여러 타입의 객체를 일괄적으로 관리하기 위한 공통된 부분을 모은 부모 클래스

이전 시간에도 다룬 내용이지만, 좀 더 자세한 내용을 다뤘다. 일반적으로 우리는 추상 클래스보다, 구체적인 클래스를 떠올리고 사용한다. 하지만 일괄적인 관리를 위해 추상 클래스를 만들게 된다.

하지만 **추상 클래스는 실제로 객체로 만들어서 사용하는 용도가 아니다**. 하지만 기존 클래스 작성 방식으로는 이것을 막을 수 없다. 따라서 추가되는 키워드가 있는데 이것이 `abstract`이다.

```java
public abstract class Shape {
    private int x;
    private int y;

    public abstract void draw();
}
```

위처럼 `abstract`을 사용하면 추상 class라는 것을 컴파일러도 인식하게 되고, 객체를 만드는 것을 막는다.

그리고 위에 `draw()`메소드 처럼 메소드에도 `abstract`을 활용할 수 있는데, 이 경우 반드시 클래스에도 `abstract`키워드가 있어야 한다.

> 추상 클래스의 속성과 메소드 접근

이전 시간에 추상 클래스인 부모 클래스에 접근하게 하는 `super`라는 키워드를 사용했다. 이를 통해 원하는 속성과 생성자, 메소드를 가져올 수 있었다. 이외에도 접근하게 할 수 있는 키워드가 있는데 그것이 `protected`이다.

`protected`는 같은 패키지에 있거나, 자식 클래스인 경우 접근 가능하게 해주는 접근자이다. 하지만, 이로 인해 캡슐화가 깨질 수 있어, 대부분의 상황에서는 `private`를 사용한다.
