# 자바의 다차원 배열

배열을 사용하다보면, 일정 데이터끼리 묶이는 경우가 생긴다. 하지만, 이걸 하나의 배열에 모두 넣고 사용하면, 계산이 어려워진다.

만약 어떤건 2개, 어떤건 4개 이렇게 다른 개수 끼리 묶이면 패턴 계산 조차 되지 않을 수 있다.

> 따라서 다차원 배열을 사용하게 되는 것이다.

## 2차원배열

> 다차원 배열 중 가장 많이 사용되는 배열이다.

~~(사실 3차원 이상인 경우면, 지금 생각한 방향이 맞는지 부터 다시 고민해볼 필요가 있다.)~~

- 초기화 형식:
    - `int[][] board = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};`
        
    - `int[][] board = new int[3][3]` -> 공간을 미리 지정
        

```java
int[][] board = new int[3][3]; // 전부 0으로 자동 채워짐

board[0][0] = 1;
board[1][1] = 5;
board[2][2] = 9;
```

- `int[][] board = new int[3][]` -> 공간 지정 X

```java
int[][] board = new int[3][]; // 행 개수만 지정

board[0] = new int[]{1};
board[1] = new int[]{1, 2};
board[2] = new int[]{1, 2, 3};
```

=> 사용할 공간의 크기가 미리 정해지지 않은 경우, 공간을 지정하지 않는 것이 동적으로 활용할 수 있다.

- 공간을 지정하지 않은 경우, 별도로 각각 1차원 배열을 초기화 해야한다.
    - 여기서 초기화 된 배열은 각각 다른 주소에 저장된다.
    - 2차원 배열에서 `board[1]`과 같은 형태는 초기화 했던 1차원 배열을 가리키는 **참조 변수**가 된다. => 2차원 배열의 행에 해당하는 곳에는 각 열이 저장된 곳을 참조하는 **참조 변수**이다.

> 위에 정리한 내용을 그림으로 옮기면 아래와 같다. ![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/2a40a2ad-4e68-49b2-a27d-0715c1136fa6.png)

- 자바의 2차원 배열은 톱니형 배열의 형태를 띈다.
    - 톱니형 배열은 각 행에 있는 열의 크기가 제각각일 수 있다는 뜻으로 그 모양이 마치 톱니처럼 위아래로 왔다갔다하는 모양이라 톱니형 배열이라고 지어졌다.
