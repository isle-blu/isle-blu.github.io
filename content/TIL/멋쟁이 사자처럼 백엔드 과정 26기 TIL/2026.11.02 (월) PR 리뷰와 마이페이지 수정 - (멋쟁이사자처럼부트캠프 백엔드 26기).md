# 오늘의 과정

리뷰를 반영하다가 폼 제출 문제를 고쳤다. JS가 로드되기 전에 폼을 제출하면 GET으로 나가서, 비밀번호가 주소창에 그대로 드러났다. 폼에 서버 액션을 지정해서 POST로 나가게 고치고, 테스트로 확인했다.

헤더 정리와 로그아웃 PR도 함께 머지했다.

## 팀원 PR 리뷰

### 채팅 기능 재리뷰

어제 요청한 4건과 역할 배지 제안이 반영된 걸 확인했다. 다시 보니 새로 2건이 보였다.

- 검색어를 입력하고 바로 다른 페이지에 갔다 오면, 검색창에는 검색어가 남아 있는데 목록은 전체가 보였다.
- Node 24에서 채팅 시각이 "AM 9:12"처럼 영어로 표시됐다.

수정된 걸 확인하고 머지했다.

### 구독 결제

의견을 2건 남겼다.

- 만료일을 조회할 때마다 새로 계산하고 있어서, 연장한 기록이 있어도 남은 기간이 고정돼 보였다. 결제 당시 만료일을 기준으로 계산하자고 했다.
- 결제 기록 쿠키의 보관 기간이 실제 이용 기간보다 짧았다. 그래서 여러 번 결제하면 이용 기간이 남아 있는데도 기록이 먼저 사라질 수 있었다.

### 개발자 프로젝트 기능

직접 테스트하면서 이런 문제들을 찾았다.

- 모집 완료 상태인데 피드백이 이미 있거나, 피드백 날짜가 모집 생성일보다 앞서 있었다. 샘플 데이터가 진행 단계와 맞지 않았다.
- 일괄 확정 후 테스터 관리 화면에서는 인원이 바뀌는데, 다른 화면은 이전 인원 그대로였다.
- 확정 요청 중 네트워크가 끊기면 실패 안내 대신 페이지 전체 오류 화면이 떴다.

## 오늘의 결정

- **상황** : 네트워크가 끊기면 오류 화면이 뜨는 문제를 찾았는데, 팀원이 오늘 작업을 할 수 없었다.
- **무엇으로 바꿨나** : 코멘트만 남기지 않고, 팀원 PR에 직접 커밋해서 이 문제를 고치고 리뷰도 반영했다.
- **왜** : 머지를 빨리 해야 했다.

## 마이페이지 수정 PR 나누기

마이페이지 수정은 연관 페이지 단위로 PR 3개로 나눴다.

1. 크레딧과 출금
2. 마이페이지 홈과 회원 개인정보
3. 회원 탈퇴 기능 추가

첫 번째 PR에서는 크레딧 이름을 "적립 크레딧 / 이벤트 크레딧"으로 바꾸고, 크레딧 내역과 출금 내역에 시각을 표시했다. 지금은 리뷰를 기다리고 있다.

# 배운 점 & 느낀 점

오늘 가장 크게 느낀 건 **역할 분담의 어려움**이었다.

백엔드 작업에 들어가기 위해 역할을 나눠야 했는데, 이게 생각보다 어려웠다. 회사라면 팀장이 역할을 정해 주겠지만, 우리는 학습을 하는 취준생이니까 각자가 배우고 싶은 부분을 가져가고 싶은 느낌이 강했다.

그래서 우선 어떻게 나눌지만 정했다. 없는 인원도 있었고, 프론트에 수정할 부분도 남아 있었기 때문이다. 내일 한 번 더 논의하고 진행할 것이다.
