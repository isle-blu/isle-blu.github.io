# 반복문 라벨링

> `break`, `continue`로 원하는 반복문을 제어하고 싶을 때 이용한다.

- `break`, `continue`는 실행된 위치의 반복문만 제어하기 때문에, 더 상단에 있는 반복문들을 제어할 수 없다. -> 이걸 가능하게 해주는 것이 바로 **반복문 라벨링**이다.

```java
OUTER:
for (int i = 2; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
        int result = i * j;
        
        if (result > 50) {
            break outer; // 바깥 루프까지 통째로 종료
        }
        
        System.out.printf("%d x %d = %d\n", i, j, result);
    }
}
```

- 위처럼 반복문에 라벨을 달면 해당 라벨을 `break`하는 방식으로 원하는 반복문을 지정해서 종료할 수 있다.

```java
OUTER:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == j) {
            continue outer; // i와 j가 같아지는 순간, 안쪽을 그만두고 바로 다음 i로
        }
        System.out.printf("i=%d, j=%d\n", i, j);
    }
}
// 출력:
// i=1, j=2
// i=1, j=3
// i=2, j=1
// i=2, j=3   ← j=2일 때 i==j라 건너뛰고 j=3만 출력됨
// i=3, j=1
// i=3, j=2
```

- `continue`도 마찬가지로 라벨로 점프해서 반복문을 이어서 진행할 수 있다.

# 배열

> 여러 값을 하나의 변수로 관리하기 위한 정적 자료구조

## 배열이 필요한 이유

컴퓨터의 저장장치는 주 저장장치(메모리)와 보조 저장장치(hdd, ssd)가 있다. 보조 저장장치는 Sequential Access 위주로 동작하고, 쓰기 작업은 수명에 부담이 된다. -> 그래서 일반적인 데이터 처리 작업은 주 저장장치인 메모리에서 이뤄진다.

- 따라서 데이터 처리의 흐름은 `디스크에서 메모리에 로드 -> 메모리에서 조작 -> 결과 저장`의 순으로 흘러간다.
- 메모리에 데이터를 로드할 때 데이터를 담아두고 작업을 하기 위한 공간이 있는데, 이게 **배열**이다.

> 정적 자료구조?

- 배열은 대표적인 정적 자료구조이다.
- 정적 자료구조는 실행 전에 공간을 할당 받으면, 그 크기를 실행 중에 바꿀 수 없다.
- 반대로 동적 자료구조는 실행 중에도 공간을 할당 받을 수 있다.

## 자바에서의 배열

|문법 형태|예시|비고|
|---|---|---|
|선언(권장)|int[] nums;|형식과 이름이 명확합니다.|
|선언(구버전 스타일)|int nums[];|과거 C계열 스타일로 남아 있으나 권장은 아닙니다.|
|생성|nums = new int[10];|길이를 지정해 메모리에 생성합니다.|
|초기화(명시, 권장)|int[] a = {1,2,3};|초기값이 있으면 길이를 따로 쓰지 않습니다.|
|초기화(명시+new)|int[] a = new int[]{1,2,3};|표현은 길지만 명확합니다.|

- 위와 같은 방식으로 배열을 선언하고 초기화 할 수 있다.
- 배열 안에 있는 값에 접근하려면 `arr[i]`와 같은 형식을 사용해야한다. `i`는 index를 의미하며, 얻고자 하는 값의 위치를 말한다.
