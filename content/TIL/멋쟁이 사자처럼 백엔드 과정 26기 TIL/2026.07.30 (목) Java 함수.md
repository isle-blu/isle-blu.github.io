# 함수

> 입력 값을 넣으면 정해진 규칙에 따라 결과를 제공하는 것

- 위 정의는 수학, 컴퓨터 모두 같은 의미로 사용된다. ![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/5bfa47d7-ff4d-451a-aaba-bdcef598222a.png)
    
- 위 그림과 같이, 형식에 약간의 차이가 있을뿐 모두 입력값에 따라 결과값이 출력된다.
    

> 컴퓨터에서 함수를 사용하는 이유

1. 추상화 / 보안 : 함수 내부가 어떻게 동작하는 지 숨기고, 함수명으로 무엇을 하는 지만 보여준다.
    
2. 코드 파편화: 복잡한 문제들을 작게 쪼개서 각각 독립적으로, 설계할 수 있게 해준다.
    
3. 유지보수 : 문제가 생겼을 때 문제가 생긴 함수만 찾아서 수정하면 된다.
    

이외에도 다양한 이유가 있지만, 이번 강의에서 주목한 곳은 **코드 파편화**이다.

- 코드 파편화에는 여러가지 장점이 있다.
    - 가독성 : 함수 이름만으로 어떤 걸 하는 함수인지 알 수 있음
    - 재사용 : 같은 기능이 필요한 여러 상황에서 함수 호출만 하면 해당 기능 사용 가능

위와 같은 장점때문에 개발 시 함수가 많이 활용된다.

# Java 함수

## 자바 함수의 형태

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/dc2455db-2227-4fed-8e1b-d7413b26ce10.png)

- **출력할 값의 타입** : 출력할 결과값의 타입을 정해주는 곳이다.
    - 기본 타입과 개인이 만든 class도 가능하다.
    - 만약 출력하지 않는 함수라면, `void`라고 표기한다.
- **매개변수** : 함수의 입력 값에 해당하는 곳이다.
    - 입력하는 값의 타입을 미리 지정해줘야한다.
    - 일종의 **지역변수**로 값 변수 같은 경우 호출한 곳과 이름이 만약 같아도, 엄연히 다른 변수다.
    - 참조 변수의 경우, 이름은 다르더라도 **같은 곳을 참조**하고 있다. 따라서 가리키는 곳에 값을 수정하면, 호출한 곳에서도 똑같이 반영된다.
    - 입력 값이 없는 함수라면, 비워둘 수 있다.
- return : 함수의 결과 값을 출력한다.
    - 정한 타입에 맞게 결과 값을 출력해야한다.
    - 출력 값이 없는 함수라면 생략할 수 있다.

2. 변수와 마찬가지로 **camelCase**를 사용한다.
