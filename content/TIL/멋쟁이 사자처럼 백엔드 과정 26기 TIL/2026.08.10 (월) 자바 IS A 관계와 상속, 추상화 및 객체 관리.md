# IS A 관계와 상속

> 다른 class의 속성과 메소드를 물려받은 관계를 IS A 관계라고 하고, 물려받는 것을 상속이라고 한다.

HAS A 관계가 객체를 속성으로 가져서 그 객체의 속성과 기능을 사용하는 방식이었다면, IS A 관계는 Class의 속성과 기능을 물려받고, 더 확장한 관계를 말한다.

물려주는 class를 **부모 class**, 물려받은 class를 **자식 class**라고 한다. 부모 class의 경우 **Framework**라고 표현하기도 하며, framework도 dependency에 해당한다.

```java
class Animal {
    String name;
    void eat() {
        System.out.println(name + "이(가) 먹는다");
    }
}

class Dog extends Animal { // "개는 동물이다"
    void bark() {
        System.out.println(name + "이(가) 짖는다");
    }
}

class Cat extends Animal { // "고양이는 동물이다"
    void meow() {
        System.out.println(name + "이(가) 야옹거린다");
    }
}
```

## Override

> 부모 class의 메소드를 재정의하는 것

자식 class는 부모 class에서 더 확장되기 때문에 메소드의 연산이나, 값에 변화가 필요할 수 있다. 이를 위해 자바에서 제공하고 있는 기능이 Overide로 부모 class의 메소드를 재정의할 수 있다.

> Override의 조건

1. 함수명이 같다.
2. 매개변수가 같다.
3. return type이 같다.

이러한 방식으로 Override를 하게되면, 부모 class에 있는 메소드가 아닌 자식 class에 있는 메소드가 호출된다.

```java
class Animal {
    void sound() {
        System.out.println("동물이 소리를 낸다");
    }
}

class Dog extends Animal {
    @Override
    void sound() { // 부모의 메서드를 재정의
        System.out.println("멍멍");
    }
}
```

```java
Animal a = new Dog();
a.sound(); // "멍멍" — 선언 타입은 Animal이지만, 실제 객체(Dog)의 것이 실행됨
```

## super

> 자식 class에서 부모 class에 접근하기 위한 키워드

자식 class에서 직접 부모 class의 속성에 접근할 수 없다. 따라서 **super**라는 키워드를 이용해, 부모 class의 생성자, Getter/Setter, 이외 메소드 등에 접근해야한다.

```java
class Shape {
    String name;

    Shape(String name) { // 부모 생성자
        this.name = name;
    }

    void printInfo() { // 부모 메서드
        System.out.println(name + " 정보:");
    }
}

class Circle extends Shape {
    Circle(String name) {
        super(name); // 부모 생성자 호출
    }

    @Override
    void printInfo() { // 오버라이딩된 메서드
        super.printInfo(); // 부모 메서드 재사용
    }
}
```

```java
Circle c = new Circle("원");
c.printInfo();
// 출력:
// 원 정보:
```

# 추상 Class

> 타입이 다른 객체의 일괄적인 관리를 위한 부모 객체를 만드는 것

개발 중, 다른 타입의 객체를 일괄적으로 관리해야하는 경우가 생길 수 있다. 이런 경우, 모두 같은 부모 class를 갖거나, 부모 class에 해당하지 않은 경우, 관리가 어렵다. 이런 경우, 일괄적인 관리를 위해 배열 안에 모두를 포괄하는 부오 class를 생성해 활용하게된다. 이렇게 생긴 class를 **추상 class**라고 한다.

만약 이들을 한번에 묶을 class가 없다면, 각각이 언제 생성됐는 지, 확인할 방법이 마땅하지 않아, 순차를 기록하기 위한 배열을 생성해야한다.

```java
public class Main {
    public static void main(String[] args) {
        Shape[] shapes = { // 타입이 다른 객체들을 Shape 하나로 묶어서 담음
            new Circle(5),
            new Rectangle(4, 6),
            new Triangle(3, 8)
        };

        for (Shape s : shapes) {
            s.printArea(); // 각자 다른 area() 구현이 실행됨
        }
    }
}
```

```java
출력:
Circle의 넓이: 78.53981633974483
Rectangle의 넓이: 24.0
Triangle의 넓이: 12.0
```

> Object class

모든 class의 **최상위 class이자, 부모 class**이다. 따라서 모든 객체를 배열로 넣을 수 있는 class이다.

하지만, 참조만 가능할 뿐, 객체에 있는 메소드를 사용할 수 없다. 사용하기 위해선 별도의 형변환이 들어가야하기 때문에, 잘 사용하지 않고 별도의 추상 class를 만든다.
