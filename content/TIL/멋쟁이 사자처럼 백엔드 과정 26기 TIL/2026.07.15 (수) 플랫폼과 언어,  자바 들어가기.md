# 플랫폼

> 누가 + 무엇을 위해 + 함께하는 공간

- 누가 : 사람, 기차, 애플리케이션 등등... => 사람이 아니어도 함께할 수 있다!
- 무엇을 위해 : 목적
- 함께하는 공간 : "누가"가 모이는 공간 (개인적으로는 공유하는 공간이 더 적합하다 느껴진다.)
- 예시
    - 기차역 : 사람을 태우거나 운송을 위해 기차가 모이는 공간
    - 인스타 : 사람들이 소통을 위해 함께 사용하는 공간
    - 도서관 : 사람들이 지식을 얻기 위해 함께하는 공간
    - 컴퓨터 : 프로그램들이 함께하는 공간
- 플랫폼이 아닌 예시
    - 계산기, 가계부....
    - 모이는 것이 아닌 혼자만 사용하는 것은 플랫폼이 아님

## 컴퓨터

> 엄청난 계산기! 정확히는 `programmable`한 전자 계산기

- 최초의 컴퓨터는 ENIAC(물론 어떤 걸 기준으로 하냐에 따라 달지기도 한다. 가장 유명한 게 에니악)
- 에니악은 개발 당시 굉장히 고성능의 **계산기**였다. 포탄의 궤적을 계산하는 `프로그램`이 들어가있다.

## 프로그램

> 실행 계획을 미리 적어놓은 것 컴퓨터에서 `programmable`을 담당

- 프로그램의 어원은 그리스어로 πρόγραμμα (prógramma) = pro(미리, 앞서) + gramma(쓰다, 기록하다) => 즉 미리 써붙이는 공고문, 공지문을 뜻했다.
- 지금의 프로그램도 미리 적는 실행계획, 명령어의 순서를 의미한다.
- `programmable`하다는 것은 실행 계획을 미리 작성해두고 그것을 실행할 수 있다는 것이다. => 컴퓨터는 이렇게 작성한 프로그램들을 위한 **플랫폼**이다.

## 운영체체(OS)

> 컴퓨터 내에서 프로그램들을 관리하는 시스템, 일종의 플랫폼

- 컴퓨터에 프로그램 여러 개를 동시에 실행시키고 싶다는 발상에서 시작 -> 프로그램을 위한 관리시스템, 플랫폼의 필요성이 대두 -> `Multics`와 같은 OS들이 개발되었지만 상용화에는 실패  
    => `Multics`에서의 경험을 바탕으로 Ken Thompson과 Dennis Ritchie가 벨 연구소에서 `UNIX`라는 OS로 상용화의 성공
- OS는 플랫폼을 이용하는 방식을 함수 형태로 제공한다.
    - 이 함수들을 사용할 수 있게, 통용된 약속이 `언어`다.
    - `UNIX`에서 사용하는 언어가 바로 **C언어**이다.
        - C언어는 `UNIX` 개발에 기여한 Dennis Ritchie가 개발했다.
- 이후 `UNIX`는 다양한 형태로 계보가 이어지고 발전해나갔다.
    - 대표 계보 : Linux, Mac OS 등등

### Linux

> 가장 대표적인 `UNIX`계열 OS는 로 정확히는 `UNIX`가 아닌 `UNIX`의 철학을 바탕으로 만들어진 OS다.

- 현재 서버 환경에서 가장 대중적으로 사용되는 OS
- Unix의 이식성을 더욱 강화해 컴퓨터, 임베디드 기기, 스마트폰, 서버 등등 대다수의 하드웨어에서 동작할 수 있게했다. => 개발자들의 선호로 이어졌다.
- 리눅스의 계보
    1. Debian : 가장 대표적인 계열로 `Ubuntou`가 여기에 속한다.
    2. Slackware
    3. Red Hat
