# 문자열 변환 함수

> 정수, 실수 등 문자열이 아닌 값을 문자열로 변환해주는 함수

- 값을 다룰 때, 값을 문자열로 변환해야하는 경우가 생길 때가 있다.
- 이 변환을 실행해주는 함수는 다음과 같다.
    - `String.valueOf()`
    - `<Wrapper Class>.toString()`

> Wrapper Class?

- `Integer`처럼 기본형(primitive type)을 객체로 만든 클래스
    
- ex) `Byte`, `Integer`, `Double`, `Float` ...
    
- 이 두 함수의 실행결과는 같다. 다만 실행의 주체가 다르다.
    
    - `String.valueOf()` : `String` 클래스에서 실행
    - `<Wrapper Class>.toString()`: 각 자료형의 클래스에서 실행
- 어떤 걸 사용하는 게 좋을까? => String.valueOf 가 더 좋을 거 같다. - 무언가를 문자열로 바꾼다는 의도를 좀 더 직관적으로 보여준다. - `String.valueOf()`의 내부적으로는 `<Wrapper Class>.toString()`를 호출하고 있다. - 사용의 범용성, 가독성 면에서 이걸 사용하는 게 더 좋다고 생각한다.

# Scanner의 next 함수들과 buffer

> `nextLine()`을 사용해보면, 입력을 하지 않았는 데 넘어가는 경우가 생긴다.

=> 입력 Buffer에 이미 들어가 있는 값이 있기 때문이다.

- 예시로 `nextInt()`를 통해 숫자를 입력하고 엔터를 누른 경우를 보자.

```java
Scanner sc = new Scanner(System.in);

System.out.print("나이: ");
int age = sc.nextInt();      // 숫자만 읽고, 뒤의 개행문자는 버퍼에 남김

System.out.print("이름: ");
String name = sc.nextLine(); // 버퍼에 남아있던 개행문자를 즉시 읽어버림 → 빈 문자열

System.out.println("이름: [" + name + "]");
```

```bash
나이: 25            ← 사용자가 25 입력 후 Enter
이름:                ← 입력할 틈도 없이 바로 넘어가버림
이름: []             ← name이 빈 문자열로 나옴
```

- 위와 같은 문제가 발생할 수 있기 때문에, **단일 값을 읽어오는 경우, nextLine()을 사용**한다. -> 이를 통해 buffer에 들거가는 개행 문자를 신경 쓰지 않아도 된다.
- 그럼 안에 값은 문자열인데? -> .parse<기본형>()을 함께 사용해, 값을 원하는 타입에 맞게 변환한다.

```java
System.out.print("나이: ");
int age = Integer.parseInt(sc.nextLine());
```

> .parse<기본형>()?

- 위에서 다른 값을 문자열로 변환했다면, 이 함수는 문자열을 원하는 자료형으로 바꾸는 함수이다.

```java
// 정수형
byte b = Byte.parseByte("100");
short s = Short.parseShort("1000");
int i = Integer.parseInt("100000");
long l = Long.parseLong("10000000000");

// 실수형
float f = Float.parseFloat("3.14");
double d = Double.parseDouble("3.141592");

// 문자형 — 참고로 char는 parse 메서드가 없음 (아래 설명 참고)

// 논리형
boolean bool = Boolean.parseBoolean("true");
```
