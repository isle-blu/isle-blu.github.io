# 자바의 변수 형식

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/5dc92e04-1f69-4c7c-a8e0-b927c79945fc.png)

- 자바의 변수 형식에는 기본 형식과 사용자(custom) 형식이 있다.
- 기본 형식에 해당하는 변수를 **값 변수**라고 하며, 변수 자체에 값이 저장되고 저장될 공간이 생긴다는 특징이 있다.

<값 변수의 종류>

|종류|자료형|
|---|---|
|정수형(4개)|`byte`, `short`, `int`, `long`|
|실수형(2개)|`float`, `double`|
|문자형(1개)|`char`|
|논리형(1개)|`boolean`|

- 사용자 형식에 해당하는 변수를 **참조 변수**라고한다.
- 참조 변수는 값을 담지 않고, 값이 저장된 공간에 대한 정보를 가진다.

---

> 참조?

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/95f14617-ec98-488a-80d5-3f9cdb9b8060.png)

- 참조는 메모리 파편화와 연관이 깊다.
- 메모리에 저장되는 객체의 크기는 다양하고, 가변적이다.
- 객체가 작업을 종료하고 메모리에서 나오면, 메모리 중간중간 빈 공간이 생긴다. => 빈공간보다 큰 객체가 올 경우, 메모리에 들어갈 자리가 없게 된다. => 그래서 자바 내부에선 주기적으로 메모리를 정리한다.
- 메모리를 정리할 때마다 객체의 주소 값이 변경된다. 변수가 참조만 하고 있다면 변수에 저장된 주소값만 바꾸면 되기 때문에 쉽게 정리할 수 있다.
- C언어의 포인터는 주소값을 변경할 수 있지만, 참조 변수는 주소 값을 변동할 수 없다. => 참조는 객체를 가리치는 표식을 가지는 것과 같다.

> 객체의 참조

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/cfe3f89a-b816-439d-83bf-fcc3801b3431.png)

- 객체는 서비스를 제공하는 역할자이자 주체이다. 위 이미지에서 보이는 함수가 그 서비스에 해당한다.
- 객체에 붙은 이름은 객체가 저장된 위치를 가리키는 참조 변수이다.
- 객체 뒤에는 서비스를 위한 데이터가 있으며, 그 데이터는 서비스를 제공받는 자들은 볼 수 없게 가려져있다.

# 문자열과 문자열 객체

> 문자열은 문자(charcter)들이 모여 이어진 것을 말한다.

- 문자를 `' '`로 표현하는 것처럼 문자열은 `" "`로 표현한다.

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/2600879a-70d5-4f40-b8eb-facfe2434539.png)

- 문자열의 크기는 (문자들의 크기 합) + (문자열 구분을 위한 이스케이프 문자 - 1byte)로 문자들의 크기 합보다 1byte 크다.

## String 객체

> 문자열을 위한 객체이다.

- `String str = "Hello"`와 같이 String 객체를 생성하면서 선언한 변수는 편의성을 위해 값 변수와 같은 형식으로 사용할 수 있다. => 하지만, 엄연한 **참조 변수**이다.

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/b283807a-b6f1-4d9c-a49e-3a0aaab9e87d.png)

- 위 그림의 `name1`과 `name2`는 별도로 생성했지만, `==` 연산을 했을 때 `true`가 나온다. => 객체 자체가 저장되는 Heap 영역 안에 있는 String Pool에 이미 같은 String 객체가 있다면, 새로 선언된 참조변수도 **이미 있는 String 객체를 가리킨다.**
- 하지만 위 그림의 `name3`처럼 `new`연산자로 생성하게 되면, Pool 밖에 저장되게 되고, 밖에 저장된 객체를 참조하게 된다. => 그래서 `name1`과 `==`연산에 false가 나오게 된다. => 추가로 `"Jane"`을 그대로 적으면 pool안에 있는 객체를 가리키기 때문에 `==`연산에 false가 나온다.
- 위와 같이 다른 객체를 가리키는 경우 같은 값인지 확인하기위해 사용하는 함수가 `equals()`이다.
