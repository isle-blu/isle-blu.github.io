## OS와 OS에 독립적인 프로그램

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/a27adf2e-6ea1-4c1d-8db4-028c2c72bad1.png)

- 이전에 컴퓨터 프로그램은 대부분 OS에 종속되어, OS에게 관리되는 프로그램이었다.
- OS에 종속되지 않고, 어떤 OS 위에서도 작동하는 프로그램을 만들기 위한 언어이자 플랫폼이 `JAVA`다.
- 현재에는 자바 이외에도, 브라우저 기반의 프로그램들이 나오면서 OS에 독립적인 프로그램들이 나오고 있다.
- 헷갈리면 안되는 게, java 기반 프로그램과 브라우저 기반의 프로그램은 모두 운영체제 위에서 돌아간다. => 하지만 어떤 OS든 상관없이 프로그램을 실행할 수 있다는 것이 핵심적인 특징이다.

## 컴퓨터 프로그래밍

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/4d88fd93-c4ba-477e-bda9-8c5a421b58c0.png)

- 우리가 사용하는 언어와 컴퓨터가 사용하는 언어는 다르다. 컴퓨터에 모든 데이터는 이진수로 저장되기 때문이다.
- 위 그림 예시에서 볼 수 있듯이, 우리가 십진수로 쓰고, 문자열을 쓰면, 컴퓨터는 데이터를 이진수로 본다.
- 사용자와 컴퓨터 사이에 번역을 담당하는 것이 **프로그래밍 언어**이고, 이 번역 과정(방식) 중 하나가 **컴파일**이다.

> 번역 방식 - 컴파일만 있는 게 아니다?

- 인터프리트 방식, JIT 등이 있다.
- 현재 사용빈도 자체는 인터프리트, JIT를 더 많이 사용한다고 한다.
- 파이썬은 인터프리트, 자바는 컴파일과 JIT를 혼합해 사용한다고 한다.

## JAVA

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/fce9087d-b360-4cc2-84dc-c7fd90774a48.png)

### C, C++, JAVA의 발전 과정

- C언어는 UNIX 개발을 위해 등장했다.
- 이후에 객체지향의 개념이 등장하고, 이 개념의 장점을 C언어의 녹여낸 것이 `C++`이다.
- JAVA는 OS에 독립적인 프로그램 개발을 위해 등장했고, 그 밑바탕이 된게 C++이다.
    - C++의 문법을 베꼈고, C++의 문제를 버렸다.
    - 이 덕분에 자바의 등장 당시 C/C++에 익숙한 개발자들이 쉽게 자바를 익힐 수 있었다고 한다.

### JAVA 프로그래밍

> 자바로 컴퓨터 프로그래밍을 하기 위한 문법들을 정리하고자 한다.

- 아래 표는 위 그림을 표로 옮긴 것이다.

|구분|문법/키워드|설명|
|---|---|---|
|구분자|`;`|실행 문장을 구분해줌|
|선언하기|`int, float ...`|내가 변수를 사용할 것이고, 어떤 자료형인지 컴퓨터에게 알려주는 것|
|출력|`System.out.print`|작성한 문자열을 터미널에 출력하는 함수|
|ㄴ 출력 방식|`println`|줄바꿈 포함 출력|
|ㄴ 출력 방식|`printf("문자열", 값)`|포맷 형식을 활용한 출력|
|ㄴ 포맷 형식|`%d`(정수-10진수), `%f`(실수), `%s`(문자열), `%c`(문자) 등|printf에서 사용하는 값의 형식 지정자|
|범위 지정|`{ }`|범위를 지정해 다른 코드와의 혼동을 줄임, 변수의 범위를 지정해 줌|
|주석|`//`, `/* */`|작동에 영향 없이 작업자, 작업현황, 기능 등을 메시지로 남기는 것|
|반복문|`while, for`|조건이 만족하면 하위에 있는 코드를 반복|

> 이제 각각을 사용하는 이유를 정리해보자.

- 구분자 : 사람은 굳이 마침표가 없어도 문장을 구분할 수 있지만, 자바의 번역기는 그렇지 않다. 한 문장이 끝날 때마다 `;`로 문장을 맞춰줘야 문장이 끝난 것을 이해한다.
- 선언하기 : 변수의 선언은 내가 이 변수를 활용할 것이라고 컴퓨터에 알리는 것이다. 하지만 자바 번역기는 이게 무슨 자료형인지를 먼저 알아야 변수라는 것을 알게 된다. 따라서 앞에 자료형을 붙이는 것이다.
- 출력 : 우리가 작성한 문자열이나 프로그램이 실행된 결과로 얻은 값 등을 터미널에 출력하고 싶을 때 사용한다.
    - `println` : `ln`은 line을 줄인 것으로 해당 line이 끝나고 줄바꿈을 한다는 뜻이다.
    - `printf` : `f`는 formatted의 앞글자로 원하는 값을 문자열에 넣어 출력하겠다는 의미다. 변수를 문자열에 그대로 넣을 수 없기 때문에 이 방식을 사용한다.
- 범위 지정 : 개발을 하다보면 코드의 길이는 기하급수적으로 늘어난다. 따라서 코드끼리 구분이 어려워진다. 그래서 같은 걸 하는 영역끼리 `{}`로 묶어서 ide에서 해당 코드를 안보이게 접을 수도 있고, 좀 더 구분이 편하게 만들 수 있다.
- 주석 : 주석은 컴퓨터가 해석하지 않는 글을 남기는 것이다. 협업할 때 작성한 작업자가 누군지 남긴다거나, 혼자 개발할 때를 포함해서 작성하는 코드가 어떤 기능인지, 현재 어디까지 진행됐는지 등을 기록하기 위해 사용한다.
- 반복문 : 상황에 따라 작성한 코드를 여러번 실행하고 싶을 때가 있을 것이다. 하지만 여러 번 사용하겠다고 같은 코드를 여러 번 붙여넣을 수는 없다. => 반복문을 통해 코드가 지정한 조건에 맞다면 반복하게 할 수 있다.
