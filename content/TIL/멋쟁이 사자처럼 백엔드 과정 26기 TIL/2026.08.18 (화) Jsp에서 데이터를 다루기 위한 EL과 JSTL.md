이전까지는 jsp파일 안에서 java 코드를 이용해 데이터를 다뤘다. 직접 객체를 초기화하거나, 서블릿으로부터 request로 포워딩한 데이터를 가져와서 다룰때도 자바 코드를 이용했다.

하지만 jsp에서 마저 자바 코드를 사용하면 기껏 MVC 모델로 분리한 이유도 사라지고, 서버 개발자가 다뤄야 하는 부분만 늘어나게 된다.

# EL(Expression Language)

> jsp에서 데이터 전달로 사용한 저장소에 데이터를 꺼내쓰기 위한 언어.

서블릿으로부터 전달받은 데이터를 활용하기 위한 **표현식 언어**로 `${<데이터>}`와 같은 형식을 사용한다. 저장소에 있는 데이터의 key값을 통해 내부 값을 가져오고 그것을 사용자에게 보여주는 역할을 수행한다.

> 데이터를 담는 저장소

데이터를 담는 저장소의 종류는 다음과 같다.

1. page : 한 페이지
2. request : forward 요청 시
3. session : 사용자와 연결된 세션
4. application : 서버의 시작과 종료

만약 저장소들이 같은 key를 사용하는 경우 1번부터 4번 순으로 확인하는 특징이 있다. 만약 같은 key를 사용하는데 우선 순위에서 밀리는 경우 `${sessionScope.name}`과 같은 방식으로 해당 저장소에 직접 접근하는 방식으로 데이터를 가져올 수 있다.

> 기타 데이터를 가져오는 방법.

저 저장소 이외에도, `param`으로 파라미터의 값을, `header`로 헤더에 있는 값을 가져올 수 있다. ip의 경우 별도로 가져오기 어려운데, `pageContext.request.remoteAddr`로 페이지에서 직접 가져오거나 setAttribute() 메서드로 직접 key와 값을 넣고 key를 통해 가져오는 방식을 사용해야한다.
