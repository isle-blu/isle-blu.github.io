# AI와 Agent

- **LLM**: 일종의 모델 파일이다. ex) gemini, claude, chatGPT ... -> 사람과의 대화로 바로 이어질 수 없다. ->
- **추론엔진**: 사람과의 대화를 할 수 있게 해줌. ex) MLX, Ollama ... +추가적으로 찾아보니 추론엔진이 모델을 돌려 추론 연산을 반복하며 대화
- 계산같은 별도의 작업은 잘하지 못함. -> AI에게 도구를 쥐어줌.

> LLM + 추론 엔진 + 도구 => AI Agent로 동작

## AI와 LLM은 어떻게 다를까?

강의를 들을 때는 못 느꼈지만, 이 둘이 같으면서도 다르게 느껴졌다. -> 이 둘의 차이를 명확하게 할 필요가 있을 것 같다.

# Web과 Internet, Web 통신에 대한 이해

## 용어 정리

Internet: 전세계를 잇는 하나의 거대한 네트워크 Web: 인터넷 상에 있는 정보들을 사용자들이 볼 수 있게 해주는 시스템

## 서버와 클라이언트

![이미지](https://cdn.likelion.net/classroom/kdt-backendj-26th/til/833ff9a8-8f32-4e4d-923a-573dc25aef8b.png)

## 서버와 클라이언트의 통신

- 인터넷을 통해 연결 / 통신
- 웹 브라우저를 통해 서버에게 요청을 날리고 결과를 시각화해서 제공

### 인터넷으로 통신하는 프로그램은 다양한데, 각각 맘대로하면 통신은 어떻게?

> Protocol(공통된 약속, 규약)을 정해서 이것에 맞게 통신

ex) HTTP - HyperText(html) 전송, FTP - 파일 전송, SMTP - 이메일 전송
